How it works

Three steps. Zero ceremony.

You don't need a 30-minute onboarding to feel the difference. Add a quest, finish it, watch progress accrue.

Step 01

Add quests, not tasks

Same gesture as any to-do app — but you tag difficulty (easy → epic) and a region. That's it.

Step 02

Finish them as you go

Check them off. XP lands. The bar fills. You won't think about it after day one — that's the design.

Step 03

Look back, not just forward

Heatmaps, streaks, region levels. The story of your week, visible in 10 seconds.

Self-host

Yours to run.
Yours to fork.

MIT licensed. One command to install — no signup, no account, no telemetry. Your data lives on your machine, full stop.

Up and running in 30 seconds.

Single curl, then open the app. SQLite by default; Postgres if you bring one. Updates with the same command. No cloud version. No premium tier. The thing is the thing.

macOS · Linux · WSL No daemon, single binary Inspect the script first ↗ 
# One-liner — install & start Questify
$ curl -fsSL https://getquestify.com/install.sh | bash

# Updates use the same command — idempotent
$ questify start
  ✓ database initialized (SQLite)
  ✓ listening on http://localhost:3030

# Open it
→ http://localhost:3030
# Docker (Postgres-ready)
$ docker run -d \
    -p 3030:3030 \
    -v questify:/data \
    questify/questify:latest

# Or with docker-compose
$ git clone github.com/questify/questify
$ cd questify && docker compose up
# macOS · Linuxbrew
$ brew install questify/tap/questify
$ questify start

# Service mode (auto-start)
$ brew services start questify
FAQ

Honest answers.

Is this just another habit tracker?
No. Questify supports habits, but the core is a full task manager — one-time tasks, projects, regions, deadlines. Habits are one verb among many.
Will the gamification annoy me on day 30?
It's designed not to. No popups, no nags, no slot-machine animations. XP and grades are visible only when you look. You can also turn the layer off entirely — Questify becomes a clean to-do app.
My data — where does it live?
On your machine. SQLite by default, in ~/.questify/. Bring Postgres if you want. There is no hosted version — nothing to leak, nothing to sell, nothing to lock behind a tier.
Is there a hosted / paid version?
Not today. Questify is self-host only. If a managed option ever ships, the self-host build will always have feature parity — same binary, same code.
Mobile?
PWA today — installable on iOS & Android, works offline, syncs to your server when you're back online. Native shells in beta this summer.
Can I migrate from Todoist / Things / Notion?
Yes. Importers for Todoist, Things, TickTick and a generic CSV. Notion is in progress.
