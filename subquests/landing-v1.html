How it works

Three habits. That's it.

No deep configuration, no "inbox zero" purity test. Questify works even if you only show up three minutes a day.

Step 01

Capture what's on your mind

Dump anything into the Inbox — a sentence is enough. Set a difficulty when you're ready, or leave it for later. Nothing is lost.

Step 02

Plan a short Today

Each morning, pull 3–7 quests into Today. The focus card tells you exactly what a good day looks like — then gets out of the way.

Step 03

Finish. Earn. Walk the path

Check things off, earn XP tied to difficulty, watch regions fill in. Grades come when the work comes — no rush, no guilt.

Open source

Yours to run, fork, bend.

Questify is MIT-licensed and self-hostable by design. You own your data. Your persona never leaves your server — unless you want it to.

One command. Your own instance.

Docker, SQLite, a single binary. No vendor lock-in, no telemetry by default, no paywalled features gated behind the cloud.

Star on GitHub Read the docs 
# Clone & run with docker compose
$ git clone https://github.com/questify/app
$ cd questify
$ docker compose up -d

# Or use the single binary
$ curl -fsSL install.questify.app | sh
$ questify serve --port 8080

# Your journey starts at http://localhost:8080

FAQ

Questions, before the quest.

Will gamification make me resent my to-do list in 3 weeks?
That's the risk of most gamified apps — streaks that shame you, numbers that only go up. We designed Questify the opposite way: no streak-breaking, optional XP, no leaderboards, and grades that unlock at your pace. You can turn any of it off. The tasks still work without the RPG on top.
Do I need to like RPGs to use it?
Not at all. If you strip the XP and grades away, Questify is a very clean task manager with habits, regions and a focused Today view. The game layer is a bonus — not a tax.
Is self-hosting really one command?
For the common setup, yes. docker compose up gets you a working instance with SQLite. There's also a single binary for Linux/macOS and a one-click deploy for Railway, Fly.io and Render.
What's the difference between the free self-host and the cloud plan?
Same features, same code. The cloud plan is just us running the server for you, plus encrypted backups, multi-device sync, and a mobile app. You can move from cloud to self-host (or back) with a JSON export at any time.
Mobile app?
iOS PWA today — native iOS and Android apps land this summer for cloud users. The web app is fully responsive in the meantime.
Who's building this?
Two people, a handful of contributors, and a growing community on Discord. We ship in public — every feature has a design thread and a GitHub issue. You're welcome to join.
